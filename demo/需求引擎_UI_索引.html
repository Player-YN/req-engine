调研结论：官方 UI 方案

Windows 原生微软风格

  • 首选原生：WinUI 3 + Windows App SDK（微软当前推荐的桌面 UI 栈，C#/C++ XAML）。
  • 设计系统：Fluent Design / Fluent 2；长驻窗口推荐 Mica 材质，标题栏可扩展到客户区。
  • 控件参考：微软商店 WinUI 3 Gallery（官方控件画廊）。
  • Web：@fluentui/web-components 或 Fluent UI React —— 适合 Web/WebView，但默认是「网页」不是「桌面窗口」。
  • 本仓库 Mock：用 HTML 模拟 Win11 独立窗口（标题栏/Mica/NavigationView），控件尽量用 Fluent Web Components。

Apple「官方 UI 库」是什么？

  • 你记得的是对的，但那是 原生 App 框架，不是像 Fluent 那样的 Web CDN：
  • SwiftUI — 跨 iOS / macOS / watchOS 等的首选声明式 UI。
  • UIKit — iOS/iPadOS 经典控件（UITableView、UINavigationBar、UITabBar、UISegmentedControl…）。
  • AppKit — 仅 macOS 桌面。
  • Apple Design Resources — 官网提供的 Figma/Sketch UI Kit 设计模板（给设计/标注用，不是可 npm 安装的前端库）。
  • Apple 没有「官方 Web Component 库」给第三方网站用；浏览器里只能做 HIG 高保真模拟。
  • 真要上架 iOS/Mac：用 Xcode + SwiftUI，设计对齐 Design Resources。
