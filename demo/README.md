# UI demos (static HTML)

Static mock / prototype pages for the Requirements Engine board.
These are **not** the shipped runtime UI — the desktop app serves
`../req-engine/web/index.html` against the real API.

| File | Platform |
|------|----------|
| `需求引擎_UI_索引.html` | Index of all demos |
| `需求引擎_UI_Windows_Fluent.html` | Windows Fluent board (mock + optional live API) |
| `需求引擎_UI_Apple_macOS.html` | macOS style board (mock) |
| `需求引擎_UI_Apple_iOS_Capture.html` | iOS capture + board (mock) |
| `需求引擎_UI_Apple_iOS_Board.html` | Redirects into the iOS capture board |
| `需求引擎_UI_Mock.html` | Early dark mock |
| `_bak/` | Old Fluent backups (ignore) |

Open `需求引擎_UI_索引.html` in a browser to browse demos.

**Product path:** double-click `../启动需求引擎.bat` for the native Windows window.
